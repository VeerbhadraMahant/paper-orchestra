## 4. Known gaps and caveats

1. **Role classifier mismatch (D8a).** The heuristic `classify_role` sends "propose/introduce" sentences to `method`, while the guidelines treat attribution of an idea as `context`. Strata are only a sampling device, but the stratum counts in the manifest are heuristic, not labels. Check a few during annotation and report the disagreement rate.
2. **Old references fall back to abstracts.** See section 2: coverage drops sharply before 2015. RQ4 (abstract vs full text) must be reported by year bucket.
3. **Subagent judge isolation is not verified (D34).** The `claude_cli` backend runs with no tools, no MCP, no session persistence, no setting sources and an empty temp working directory, but it has not been confirmed that user memory files are excluded. Treat Claude results as possibly contaminated until checked.
4. **Dev data stays local.** The dev survey is unpublished and lives only in git-ignored `.work/dev/`. Nothing from it is in the fork.
5. **Reviewer items not fixed:** no tooling yet for the D18 20-pair check, and McNemar and ECE exist in `evaluate.py` but are not wired into the CLI.
6. **No test-set judge runs and no labels exist yet.** Every number in `SMOKE.md` is a pipeline check, not a result.
